# RAHE – Emergency Hospital Bed Finder

Emergency Hospital Bed Finder is a web-based application that helps users find hospitals with available beds during emergency situations.

## Features

- Hospital search
- General, ICU and Emergency bed availability
- District and city based search
- Emergency contacts
- Hospital login and dashboard
- Hospital bed management
- Distance and location information

## Technologies

- Python
- Flask
- HTML
- CSS
- SQLite
